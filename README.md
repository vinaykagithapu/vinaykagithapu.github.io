# vinaykagithapu.github.io

Personal portfolio & technical blog of **Vinay Kagithapu** — AI Infrastructure &
Platform Engineer (LLM Systems · Kubernetes · DevSecOps).

**Live site:** [https://vinaykagithapu.github.io](https://vinaykagithapu.github.io)

Built with [Docusaurus 3.9](https://docusaurus.io/), dark-first "cloud native"
design, Mermaid diagrams, and RSS/Atom feeds. Deployed to GitHub Pages from the
`gh-pages` branch.

## What's inside

| Section | Path | Notes |
| --- | --- | --- |
| Homepage / About / Projects | `src/pages/` | React pages (`index.js`, `about.md`, `projects.js`) |
| Tutorials | `docs/` | OpenCode Guide, MLOps, DevOps, DevSecOps, Security |
| Blog | `blog/` | Folder-per-post (`YYYY-MM-DD-slug/index.md`), tags in `blog/tags.yml` |
| Design system | `src/css/custom.css` | Colors, typography, components — edit here |
| Navbar brand override | `src/theme/Logo/` | Swizzled: a11y label + homepage active indicator |
| Static assets | `static/img/` | logo, favicon, social card, author avatar |

## Quick start

```bash
npm install
npm run build
npm run serve          # http://localhost:3000
```

Dev server with live reload:

```bash
npm run start
```

> **Package manager: npm only.** This repo uses `package-lock.json` — there is
> deliberately no `yarn.lock`. (Both used to be tracked, which made Docusaurus's
> update notifier shell out to `yarn --version` and crash the CLI on machines
> without yarn. `NO_UPDATE_NOTIFIER=1` is now optional — it only silences the
> "update available" banner.)

## Deployment

Deploy is handled by the `.opencode/skills/site-publish` skill (feature branch →
PR → merge → `docusaurus deploy` to `gh-pages`, with post-deploy verification).

Manual deploy:

```bash
GIT_USER=<your-github-username> NO_UPDATE_NOTIFIER=1 npm run deploy
```

Secrets (GitHub token, deploy identity) live in `.env` — see `.env.example`.
`.env` is gitignored; never commit real tokens.
