# Claude Code

**Claude Code** is Anthropic's terminal-native coding agent. Built around Claude, it works over the command line and is a strong alternative to OpenCode when you prefer Anthropic's models and a terminal-first agent workflow.

## What it's good for

- **Terminal-native agentic coding** — plan, edit, and run from the command line
- **Claude models** — strong reasoning and code generation from Anthropic
- **Command-line workflow** — fits naturally into terminal-centric development

## Trade-offs

| Pros | Cons |
|------|------|
| Claude's strong coding ability | Not open source |
| Terminal-first agent workflow | Tied to Anthropic's Claude |
| No IDE required | Less model flexibility than OpenCode |

## When to choose Claude Code

Choose Claude Code when you want a **terminal agent powered by Claude** and you're comfortable within Anthropic's model ecosystem. If you want open source and the freedom to switch between Anthropic, OpenAI, Google, OpenRouter, or local models, [OpenCode](/docs/ai-tools/opencode) is the better fit.
