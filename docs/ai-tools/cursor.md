# Cursor

**Cursor** is an AI-native code editor (a fork of VS Code) that brings AI chat, autocomplete, and multi-file editing directly into the editor. It's a strong choice when you want AI pair-programming inside a familiar IDE with a graphical interface.

## What it's good for

- **In-editor AI chat** — ask questions about your codebase without leaving the editor
- **Autocomplete** — predicts your next edit across multiple lines
- **Multi-file edits** — describe a change and Cursor applies it across files
- **VS Code compatibility** — your extensions, themes, and keybindings carry over

## Trade-offs

| Pros | Cons |
|------|------|
| Polished IDE experience | Not open source |
| Great autocomplete + chat | Subscription-based |
| Familiar VS Code UI | Tied to specific model providers |

## When to choose Cursor

Choose Cursor when you want AI assistance **inside a visual editor** and prefer a graphical interface over the terminal. If you want open source, any model, and full terminal agency, [OpenCode](/docs/ai-tools/opencode) is the better fit.
